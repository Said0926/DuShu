# Dúshū — дизайн-спецификация

Документ для реализации вёрстки. Все значения цветов, шрифтов, отступов и радиусов
лежат в `tokens.css` — в компонентных стилях используй только переменные оттуда,
никаких хардкод-хексов.

Направление: тёмная «фокус»-тема. Глубокий сине-серый фон, один тёплый акцент
(киноварь), цвета тонов — единственная яркая вещь в тексте.

---

## 1. Файлы стилей

```
static/css/
  tokens.css      — переменные (этот пак), подключается первым
  base.css        — reset, типографика, шапка/подвал, кнопки, переключатели
  reader.css      — страница «Чтение»
  shadowing.css   — страница «Shadowing»
```

Инлайн-CSS и стили внутри JS не используются. JS меняет только классы и
`data-`атрибуты.

## 2. Шрифты

Подключаются одним `<link>` в `base.html`:

```html
<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@500;600;700&family=Manrope:wght@400;500;600;700&family=Noto+Serif+SC:wght@400;500;600&display=swap">
```

- `--font-display` (Cormorant Garamond) — только крупные заголовки: hero на главной, `h1` страницы.
- `--font-ui` (Manrope) — весь интерфейс, переводы и пиньинь.
- `--font-cn` (Noto Serif SC) — иероглифы.

## 3. Разметка китайской строки

Иероглиф и пиньинь — настоящие `<ruby>` / `<rt>`. Слово — отдельный элемент с
`data-`атрибутами, как в ТЗ, чтобы к подсказке потом добавилась кнопка
«в мой словарь».

```html
<p class="reader__sentence-line">
  <button class="word" type="button"
          data-word="打算" data-pinyin="dǎ suàn">
    <ruby><span class="tone-3">打</span><rt>dǎ</rt></ruby><ruby><span class="tone-4">算</span><rt>suàn</rt></ruby>
  </button>
  <span class="punct">，</span>
</p>
<p class="reader__translation">Сегодня хорошая погода…</p>
```

Правила:

- Слово — `<button type="button">`, а не `<span>`: работает Tab и скринридер.
  Сбрасывается `border:none; background:transparent; color:inherit; font:inherit;`.
- Класс тона (`tone-1`…`tone-5`) вешается на `<span>` внутри `<ruby>`, не на слово:
  в слове слоги бывают разных тонов.
- `rt` — размер `calc(1em * var(--ruby-ratio))`, цвет `--color-text-3`,
  шрифт `--font-ui`. Он в `em`, поэтому ползунок размера шрифта тянет обе строки сразу.
- Знаки препинания не попадают внутрь слов — отдельный `<span class="punct">`.
- Строка предложения — `display:flex; flex-wrap:wrap; column-gap:3px; row-gap:20px;
  align-items:flex-end;`. Не полагайся на пробелы между инлайн-элементами.

Переключатели рендерятся классами на контейнере `.reader`:
`pinyin-off` (прячет `rt` через `display:none`), `tones-off` (см. `tokens.css`),
`translation-off` (прячет `.reader__translation`), `hints-off` (отключает попап).
Размер шрифта — `font-size` на `.reader`: `var(--reader-sm|md|lg)`.

## 4. Подсказка по слову (popover)

Показывается при `mouseenter` на десктопе и при `click`/`tap` на телефоне.
Позиционируется относительно слова: `position:absolute; left:50%;
bottom:calc(100% + 14px); transform:translateX(-50%);`.

- ширина 266px, фон `--color-surface-2`, рамка `--color-line-pop`,
  радиус `--radius-md`, тень `--shadow-popover`;
- строка 1: иероглифы `--font-cn` 21px `--color-text`, рядом пиньинь 14px/600
  `--color-accent`;
- строка 2: перевод 14px `--color-text-2`, line-height 1.5.

Активное слово получает фон `--color-accent-soft` и подчёркивание
`box-shadow: inset 0 -2px 0 var(--color-accent)`.

Если слова нет в словаре — та же карточка, но перевод собирается из отдельных
иероглифов (каждый на своей строке).

## 5. Компоненты интерфейса

**Шапка** — высота `--nav-height`, нижняя граница `--color-line`, отступы по
`--space-16`. Три блока через `justify-content:space-between`: логотип
(плитка 36×36, радиус 10, фон `--color-accent`, иероглиф 读 цветом
`--color-on-accent`) + вордмарк `--font-display` 25px; навигация (15px,
`--color-text-2`); справа статус лимита и аватар.
Активный пункт: `--color-text`, вес 600, `box-shadow: inset 0 -2px 0 var(--color-accent)`.

**Кнопки** — высота `--control-height`, радиус `--radius-md`, 14–15px.
Primary: фон `--color-accent`, текст `--color-on-accent`, вес 600.
Ghost: прозрачный фон, рамка `--color-line-strong`, текст `--color-text`.

**Сегментированный контрол** (язык перевода, размер шрифта, скорость, режим паузы) —
контейнер `--color-surface-2` + рамка `--color-line-strong`, радиус `--radius-pill`,
внутренний padding 3px. Активный сегмент: фон `--color-accent`,
текст `--color-on-accent`, вес 600. Неактивный: прозрачный, `--color-text-2`.

**Переключатель** — вся строка настройки это `<button role="switch" aria-checked>`
на всю ширину, высота 48px: слева подпись, справа дорожка
`--switch-width`×`--switch-height`, радиус 13px. Вкл: дорожка `--color-accent`,
кружок `--color-on-accent`, `justify-content:flex-end`. Выкл: дорожка
`--switch-off`, кружок `--switch-knob-off`.

**Панель** (сайдбар, список предложений) — фон `--color-surface`, рамка
`--color-line`, радиус `--radius-lg`, padding 20–22px.
**Полотно чтения / сцена** — фон `--color-panel`, та же рамка и радиус,
padding 40px 44px.

## 6. Страница «Чтение»

Сетка: шапка, затем колонка с отступами `28px var(--space-16) 40px`.
Строка заголовка (название текста `--font-display` 34px + мета-строка
`--text-caption` `--color-text-3`; справа «Сохранить в библиотеку» ghost и
«Открыть в Shadowing» primary). Ниже — `display:flex; gap:var(--space-8);
align-items:stretch`: полотно чтения 960px и сайдбар настроек 320px.

Сайдбар сверху вниз: заголовок-лейбл; четыре переключателя (пиньинь, перевод
предложений, цвета тонов, подсказки); разделитель; «Язык перевода» —
сегментированный контрол русский/English; «Размер шрифта» — три сегмента
«Аа» кеглем 13/16/20 с `aria-label`; разделитель; легенда тонов (квадратик
24×24 с фоном `цвет тона + 29` альфой и номером, подпись, справа образец
mā/má/mǎ/mà/ma); внизу примечание, что настройки сохраняются в профиле, а
без входа — в браузере.

Между предложениями `gap: 30px`, между строкой и переводом `gap: 12px`.
Перевод: 16px/1.55, `--color-text-3`, ширина не больше 760px.

## 7. Страница «Shadowing»

Та же сетка, но слева список предложений 360px, справа сцена (`flex-grow:1`).

Список: строка 66px, радиус `--radius-md`, внутри номер-бейдж 26×26, текст
предложения `--font-cn` 17px с `text-overflow:ellipsis`, справа длительность.
Состояния: текущее — фон `--color-surface-2` + `inset 0 0 0 1px #3A424D`, бейдж
на акценте; пройденное — текст и бейдж `--color-text-4`; впереди — `--color-text-2`.

Сцена сверху вниз:

1. Строка статуса: «Предложение N из M» слева, «Повтор k / n» справа с иконкой повтора.
2. Текущее предложение по центру, `--font-cn` 50px, `row-gap:24px`. Активное слово —
   фон `--color-accent-strong` + `inset 0 -3px 0 var(--color-accent)`, радиус 10px.
   Цвета тонов при этом сохраняются.
3. Прогресс: таймер слева, дорожка 6px (`--switch-off`) с заливкой `--color-accent`, таймер справа.
4. Транспорт по центру: назад / повторить предложение / play-pause / вперёд —
   квадратные кнопки 52×52 с рамкой `--color-line-strong`, кроме центральной:
   76×76, радиус 26, фон `--color-accent`, тень `--shadow-accent`.
   Рядом сегментированный контрол скорости: 0,5× 0,75× 1× 1,25× 1,5×.
5. Разделитель, ниже настройки в строку: «Пауза после предложения»
   (авто ×1,5 / фикс. 2 с), «Повторов» (степпер − N +), справа переключатели
   пиньиня и цветов тонов.

Переводов на этой странице нет — только иероглифы и пиньинь.

## 8. Главная

Шапка, затем по центру: эйбрау-строка капсом на акценте между двумя линиями 1px,
hero-заголовок `--font-display` 78px/1.02 в две строки, подзаголовок 18px/1.65
шириной до 660px.

Дальше карточка ввода 960px: внешний контейнер `--color-surface` + рамка
`--color-line-strong`, радиус `--radius-xl`, тень `--shadow-card`; внутри
поле на фоне `--color-bg` с рамкой `--color-line` — `<label>` капсом и
`<textarea>` `--font-cn` 24px/1.75 без рамки и ресайза, плейсхолдер
`今天天气很好，我打算去公园走走。` цветом `#5F6975`. Под полем: слева сегментированный
контрол языка и счётчик «0 / 5 000 символов», справа ghost «Shadowing» и primary
«Читать →». Под карточкой — строка про лимиты 13px `--color-text-3`.

Ниже блок-превью строки чтения (с легендой тонов в шапке блока) и три карточки
с короткими объяснениями: пиньинь по словам, локальный словарь, караоке-подсветка.
Подвал 84px с верхней границей.

## 9. Адаптив

Брейкпоинт 900px:

- отступы страницы `--space-16` → `--space-4`;
- обе страницы становятся одной колонкой, сайдбар настроек уезжает в
  выдвижную панель снизу (кнопка «Настройки» в строке заголовка);
- размер чтения по умолчанию `--reader-sm`;
- подсказка по слову открывается по тапу и прижимается к нижнему краю экрана
  на всю ширину минус 16px, а не позиционируется над словом;
- в Shadowing список предложений сворачивается в горизонтальную ленту над сценой,
  транспорт остаётся зафиксированным снизу.

Минимальная высота любой интерактивной цели — 44px, она же `--control-height`.

## 10. Доступность

- Контраст текста ≥ 4.5:1 на своём фоне; `--color-text-3` — минимально
  допустимый серый, ниже не опускаться.
- У кнопок только с иконкой обязателен `aria-label`.
- Переключатели — `role="switch"` + `aria-checked`, сегментированные контролы —
  `aria-pressed` на активном сегменте.
- Видимый фокус: `outline: 2px solid var(--color-accent); outline-offset: 2px`.
- Караоке-подсветка дублируется не только цветом, но и подчёркиванием.
